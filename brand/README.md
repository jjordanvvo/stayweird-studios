# Stay Weird Studios brand logos

Each logo comes in -black.png (for light backgrounds, tags, white tees) and -white.png (for dark backgrounds, black tees). Transparent background.

- sw-monogram: main SW mark (tags, chest hits, social profile picture)
- badge: round SW badge with STAY WEIRD STUDIOS / EST. 2026 (stickers, neck prints, packaging)
- wordmark-studios: Stay Weird with STUDIOS underneath
- block-lockup: SW box + name side by side

preview-dark.jpg and preview-light.jpg show all four together.
Regenerate with: python3 tools/make_brand_logos.py brand
