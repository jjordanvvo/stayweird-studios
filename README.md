# Stay Weird Studios

Static storefront (plain HTML/CSS/JS, no build step), deployed on Vercel at stayweirdstudios.app.

- **Products:** `assets/products.js` (name, price, sizes, sold-out sizes, image paths)
- **Colors & font:** variables at the top of `assets/styles.css`
- **Layout (header, menu, cart, footer):** `assets/app.js`
- **Pages:** `index.html`, `shop.html`, `product.html`, plus info pages

Photos and copy are placeholders. Checkout still needs a store backend (e.g. Shopify).

Run locally: `npx serve .`
